RouteShareApp — Microservice Architecture

Passenger app + Driver app + Admin web/live APIs for planned-route ride sharing

Core architecture

  • Spring Boot microservices behind API Gateway
  • PostgreSQL + PostGIS as system of record
  • Kafka/Redpanda for event-driven trip/location/payment flows

Route intelligence

  • H3 + PostGIS candidate filtering
  • Exact full/partial route overlap validation
  • Ranking by overlap, time, price, proximity, driver quality

Realtime tracking

  • Raw GPS ingestion + map matching
  • Redis latest-location cache + WebSocket fanout
  • Client animation for smooth vehicle movement; backend matched distance for fare
